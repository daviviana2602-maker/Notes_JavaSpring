=============== Rotina (SCHEDULER) ===============


┌──────── segundo
│ ┌────── minuto
│ │ ┌──── hora
│ │ │ ┌── dia do mês
│ │ │ │ ┌ mês
│ │ │ │ │ ┌ dia da semana
│ │ │ │ │ │
* * * * * *


exemplos:

// Todo minuto
@Scheduled(cron = "0 * * * * *")


// Toda hora
@Scheduled(cron = "0 0 * * * *")


// Todo dia meia-noite
@Scheduled(cron = "0 0 0 * * *")


// A cada 10 minutos
@Scheduled(cron = "0 */10 * * * *")


- Também existem:

    @Scheduled(fixedRate = 60000)
    executa a cada 90 minutos contando a partir do início da execução anterior

    @Scheduled(fixedDelay = 90 * 60 * 1000)
    executa a cada 90 minutos contando depois que a execução anterior termina
